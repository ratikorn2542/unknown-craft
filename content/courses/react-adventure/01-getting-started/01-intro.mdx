# React คืออะไร?

## รู้จักกับ React

React คือ **JavaScript library** สำหรับสร้าง user interfaces

### ทำไมต้องเรียน React?

| เหตุผล | อธิบาย |
|---------|--------|
| 🔥 ดึงดูด | ใช้งานเยอะมากในตลาด |
| 📈 โอกาส | มีงานด้าน React เยอะ |
| 🛠️ เครื่องมือดี | มี ecosystem ใหญ่ |
| 📱 Multi-platform | React Native สำหรับ mobile |

## React ทำอะไรได้บ้าง?

- 🌐 เว็บไซต์ (Next.js)
- 📱 แอปมือถือ (React Native)
- 🖥️ แอป desktop (Electron + React)
- 🎮 เกม (React Three Fiber)

## เริ่มต้นยังไง?

```bash
npx create-next-app@latest my-app
cd my-app
npm run dev
```

เปิด http://localhost:3000

ยินดีด้วย! คุณสร้าง React app แรกแล้ว! 🎉
