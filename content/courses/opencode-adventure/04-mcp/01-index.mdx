# MCP (Model Context Protocol)

## MCP คืออะไร?

**MCP (Model Context Protocol)** คือ protocol ที่ช่วยให้ AI สามารถเชื่อมต่อกับเครื่องมือและบริการภายนอกได้

## ทำไมต้องมี MCP?

ปกติ AI อย่างเดียว:
- ❌ ไม่รู้ข้อมูลล่าสุด
- ❌ ไม่สามารถทำ action ได้
- ❌ ไม่เข้าถึงไฟล์ในเครื่องได้

แต่ถ้ามี MCP:
- ✅ ค้นหาข้อมูลล่าสุดได้
- ✅ ทำ action ต่างๆ ได้
- ✅ เข้าถึงไฟล์และโปรแกรมได้

## MCP Servers ยอดนิยม

| Server | ทำอะไรได้ |
|--------|----------|
| File System | อ่าน/เขียนไฟล์ |
| Git | ทำงานกับ Git |
| Web Search | ค้นหาข้อมูลบนเว็บ |
| Database | เชื่อมต่อฐานข้อมูล |
