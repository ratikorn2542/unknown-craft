# Channel

## Channel คืออะไร?

Channel คือช่องทางการสื่อสารระหว่างคุณกับ Opencode

### ประเภทของ Channel

| Channel | คำอธิบาย |
|---------|----------|
| CLI | ใช้ผ่าน Command Line |
| Desktop App | ใช้ผ่านโปรแกรมบนเดสก์ท็อป |
| VS Code Extension | ใช้ผ่าน VS Code โดยตรง |

### การเลือก Channel

- **ถ้าชอบ Terminal** → ใช้ CLI
- **ถ้าชอบ GUI** → ใช้ Desktop App
- **ถ้าเขียนโค้ด** → ใช้ VS Code Extension
