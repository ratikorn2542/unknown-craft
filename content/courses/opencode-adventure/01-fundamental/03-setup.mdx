# Setup

## การติดตั้ง Opencode

### ขั้นตอนที่ 1: ติดตั้งผ่าน npm

```bash
npm install -g opencode
```

### ขั้นตอนที่ 2: ตรวจสอบการติดตั้ง

```bash
opencode --version
```

### ขั้นตอนที่ 3: เริ่มใช้งาน

```bash
opencode
```

ถ้าติดตั้งสำเร็จจะเห็นหน้าต่างแชทเปิดขึ้นมา 🚀

## การตั้งค่าเริ่มต้น

หลังติดตั้ง ควรตั้งค่า:
- API Key สำหรับ LLM ที่ต้องการใช้
- Default language
- Theme ที่ชอบ
