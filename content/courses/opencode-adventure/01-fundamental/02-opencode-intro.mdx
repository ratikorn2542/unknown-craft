# Opencode คืออะไร?

Opencode คือ **AI Agent** ที่ช่วยให้คุณทำงานได้เร็วขึ้น โดยสามารถ:

- 🔍 ค้นหาข้อมูลให้อัตโนมัติ
- 📝 เขียนโค้ดและแก้ไขข้อผิดพลาด
- 📁 จัดการไฟล์และโปรเจค
- 🌐 เชื่อมต่อกับบริการต่างๆ
- 🤖 ทำงานซ้ำๆ แทนคุณ

## ทำไมต้องใช้ Opencode?

ปกติเวลาเราทำงาน เราต้อง:
1. ค้นหาข้อมูลเอง
2. เขียนโค้ดเอง
3. Debug เอง

แต่ Opencode ช่วยทำทุกอย่างนี้แทนคุณ! 🚀
