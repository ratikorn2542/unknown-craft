# Context Window และ System Role

## Context Window คืออะไร?

Context Window คือ **ขนาดของข้อมูลที่ LLM สามารถจำได้ในครั้งเดียว**

เปรียบเหมือนกับสมองของมนุษย์ที่มีความจำทำงานได้ในช่วงเวลาหนึ่ง

## System Role คืออะไร?

System Role คือ **บทบาทที่เรากำหนดให้ AI** เช่น:

- คุณเป็น Developer ที่เก่ง
- คุณเป็น Teacher ที่ใจดี
- คุณเป็น Code Reviewer ที่เข้มงวด

## การตั้งค่า Context และ System Role

ใน Opencode คุณสามารถ:

1. กำหนด Context size ตามความต้องการ
2. กำหนด System Role ให้เหมาะกับงาน

> 💡 ถ้างานซับซ้อน ควรใช้ Context ใหญ่ขึ้น
