# LLM และ AI Agent

## LLM คืออะไร?

LLM ย่อมาจาก **Large Language Model** คือโมเดลภาษาขนาดใหญ่ มีความเข้าใจภาษามนุษย์เป็นอย่างดี เช่น Gemini, GPT, Claude เป็นต้น

หลักการทำงานของ LLM คือ **การเดาคำถัดไป** ที่ใกล้เคียงที่สุด ตาม prompt ที่ผู้ใช้ป้อนเข้าไป

<Callout emoji="🤖" title="ลองนึกภาพ...">

ตัวอย่างเช่น เมื่อป้อนประโยค: **"ท่าน กำลัง เข้า สู่ บริการ รับ ฝาก หัว ____"**

LLM จะเดาคำถัดไป:

- ใจ 98.5% 🎯
- ขโมย 1.0%
- มัน 0.3%

</Callout>

## ข้อจำกัดของ LLM

<CalloutWarning title="ข้อจำกัดที่สำคัญ">

LLM มีข้อจำกัดอยู่ 2 ประการ:

1. **เป็น Passive** - มันจะทำงานก็ต่อเมื่อผู้ใช้ป้อนคำถามไป AI ก็ตอบ
2. **ไม่มีแขนขา** - สามารถคิดได้แต่ลงมือไม่ได้

</CalloutWarning>

ยกตัวอย่างเช่น LLM สามารถบอกวิธีการสั่งซื้อของ Online จากเว็บ Amazon ได้ แต่ไม่สามารถกดสั่งซื้อแทนผู้ใช้งานได้

## AI Agent คืออะไร?

พอผู้พัฒนาเริ่มรู้สึกว่า LLM (สมอง) มันฉลาดมากพอแล้วแต่อยากให้มันทำได้มากกว่าแค่ตอบคำถาม จึงได้เริ่มพัฒนาระบบที่ทำให้ AI สามารถใช้เครื่องมือได้ จนกลายเป็น **AI Agent** ในที่สุด

<InfoBox title="ตัวอย่าง">

ถ้าอยากให้ LLM ค้นหา Google ได้ เราก็แค่บอก AI ว่า "เรามีเครื่องมือ google ให้ใช้สำหรับค้นหาข้อมูลนะ"

LLM ก็จะเริ่มมีแขนมีขา สามารถค้นหา Google แทนเราได้! 🔍

</InfoBox>

## ส่วนประกอบสำคัญของ AI Agent

<Checklist>

<ChecklistItem>

**1. Core Brain (LLM)** - สมองส่วนกลางที่ใช้คิด วิเคราะห์ และทำความเข้าใจคำสั่ง

</ChecklistItem>

<ChecklistItem>

**2. Planning (การวางแผน)** - Agent สามารถย่อยเป้าหมายใหญ่ให้กลายเป็น Task ย่อยๆ เองได้

</ChecklistItem>

<ChecklistItem>

**3. Memory (ความจำ)** - จำบริบทที่กำลังคุยหรือทำอยู่ และสามารถบันทึกข้อมูลเก็บไว้ใช้ในอนาคต

</ChecklistItem>

<ChecklistItem>

**4. Tools (เครื่องมือ/แขนขา)** - จุดเปลี่ยนสำคัญ! Agent ได้รับอนุญาตให้ใช้เครื่องมือภายนอกได้

</ChecklistItem>

</Checklist>
