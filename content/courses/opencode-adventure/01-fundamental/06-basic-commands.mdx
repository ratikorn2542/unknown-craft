# Basic Commands

## คำสั่งพื้นฐาน

### /ask - ถามคำถาม

```bash
/ask "วิธีสร้าง React component"
```

### /search - ค้นหาข้อมูล

```bash
/search "วิธีใช้ Git"
```

### /code - เขียนโค้ด

```bash
/code เขียนฟังก์ชันบวกเลข
```

## คำสั่งอื่นๆ

| คำสั่ง | คำอธิบาย |
|--------|----------|
| `/help` | แสดงวิธีใช้ |
| `/clear` | ล้างบทสนทนา |
| `/save` | บันทึกบทสนทนา |
