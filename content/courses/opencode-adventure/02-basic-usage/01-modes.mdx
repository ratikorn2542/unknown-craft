# Mode

## Mode คืออะไร?

Mode คือ **โหมดการทำงาน** ของ Opencode ที่เหมาะกับงานต่างๆ

### โหมดที่มี

| Mode | คำอธิบาย | ใช้เมื่อ |
|------|----------|----------|
| **Auto** | อัตโนมัติเลือกโหมดที่เหมาะสม | ไม่แน่ใจว่าควรใช้โหมดไหน |
| **Code** | โหมดเขียนโค้ด | ต้องการเขียนหรือแก้โค้ด |
| **Chat** | โหมดสนทนา | ถามตอบทั่วไป |
| **Research** | โหมดค้นคว้า | ต้องการหาข้อมูล |

## การเปลี่ยน Mode

```bash
/mode code
```

หรือใช้ผ่าน UI:
1. คลิกที่ Mode ปัจจุบัน
2. เลือก Mode ใหม่ที่ต้องการ
