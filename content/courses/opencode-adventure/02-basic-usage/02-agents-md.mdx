# AGENT.md

## AGENT.md คืออะไร?

AGENT.md คือ **ไฟล์ที่กำหนดบทบาทและพฤติกรรม** ของ Opencode สำหรับโปรเจคของคุณ

## การสร้าง AGENT.md

สร้างไฟล์ `AGENT.md` ใน root ของโปรเจค:

```markdown
# Agent Configuration

## Role
คุณเป็น Senior Developer ที่เชี่ยวชาญ React และ TypeScript

## Rules
1. เขียนโค้ดตาม best practices
2. อธิบายการทำงานของโค้ดทุกครั้ง
3. เขียน tests สำหรับทุก function
```

## การใช้งาน

Opencode จะอ่านไฟล์นี้อัตโนมัติเมื่อทำงานในโปรเจค
