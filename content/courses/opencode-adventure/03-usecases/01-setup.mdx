# Setup

## การตั้งค่าสำหรับ Use Cases

ก่อนเริ่มใช้งาน Use Cases ต่างๆ ต้องตั้งค่าเบื้องต้นก่อน

### 1. ติดตั้ง Opencode

```bash
npm install -g opencode
```

### 2. ตั้งค่า API Keys

เพิ่ม API keys ที่จำเป็นในไฟล์ `.env`:

```bash
OPENAI_API_KEY=your-key
GOOGLE_API_KEY=your-key
```

### 3. ตั้งค่าโปรเจค

```bash
opencode init
```

## พร้อมแล้ว!

หลังจากตั้งค่าเสร็จ คุณสามารถใช้งาน Use Cases ต่างๆ ได้เลย 🚀
