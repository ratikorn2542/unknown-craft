# Code / Dev

## Opencode สำหรับนักพัฒนา

Opencode เป็นเครื่องมือที่ช่วยนักพัฒนาได้มาก!

### 🔥 สิ่งที่ทำได้

| งาน | คำสั่งตัวอย่าง |
|------|----------------|
| เขียนโค้ด | `/code เขียนฟังก์ชัน API` |
| แก้ bug | `/fix ช่วยหา bug นี้` |
| เขียน test | `/test เขียน tests สำหรับ function นี้` |
| Review code | `/review ดู code นี้ให้หน่อย` |
| อธิบายโค้ด | `/explain อธิบายโค้ดนี้` |

### 💻 ตัวอย่างการใช้งาน

#### เขียน React Component:
```
/code เขียน React component สำหรับปุ่มที่มี loading state
```

#### แก้ Bug:
```
/fix มี bug ใน function นี้ ช่วยหาหน่อย
```

#### เขียน Tests:
```
/test เขียน unit tests สำหรับ calculator function
```

### 🎯 เคล็ดลับ

1. **ให้ context เยอะๆ** - บอกรายละเอียดของโปรเจค
2. **บอก requirements** - บอกว่าต้องการอะไร
3. **ขอ alternatives** - ถามวิธีทำที่ดีกว่าได้
