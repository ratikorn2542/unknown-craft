# Commands

## Commands พื้นฐาน

| Command | คำอธิบาย |
|---------|----------|
| `/help` | แสดง help |
| `/clear` | ล้างบทสนทนา |
| `/save` | บันทึกบทสนทนา |
| `/load` | โหลดบทสนทนา |
| `/mode` | เปลี่ยนโหมด |
| `/config` | ตั้งค่า |

## Commands ขั้นสูง

### /search

ค้นหาข้อมูลบนเว็บ:

```
/search "React best practices 2024"
```

### /code

เขียนโค้ด:

```
/code เขียน function คำนวณ BMI
```

### /explain

อธิบายโค้ด:

```
/explain อธิบายโค้ดนี้
```

### /refactor

ปรับปรุงโค้ด:

```
/refactor ปรับโค้ดนี้ให้ดีขึ้น
```

## การสร้าง Commands ของตัวเอง

```bash
/opencode commands create mycommand "คำอธิบาย"
```
