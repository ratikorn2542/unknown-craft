# Skill

## Skill คืออะไร?

Skill คือ **ความสามารถพิเศษ** ที่คุณสามารถเพิ่มให้ Opencode

## การใช้ Skill

### ดู skills ที่มี

```bash
/opencode skills list
```

### ติดตั้ง skill ใหม่

```bash
/opencode skills install <skill-name>
```

## Skills ที่แนะนำ

| Skill | คำอธิบาย |
|-------|----------|
| `web-search` | ค้นหาข้อมูลบนเว็บ |
| `file-operations` | จัดการไฟล์ |
| `git-helper` | ช่วยงาน Git |
| `code-explainer` | อธิบายโค้ด |

## การสร้าง Skill ของตัวเอง

คุณสามารถสร้าง skill ของตัวเองได้โดย:

1. สร้างไฟล์ `skills/my-skill.ts`
2. กำหนดฟังก์ชันที่ต้องการ
3. ทดสอบการทำงาน
