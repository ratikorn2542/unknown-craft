# Agentic Browser

## Agentic Browser คืออะไร?

Agentic Browser คือ **AI ที่สามารถใช้งานเว็บไซต์แทนคุณ** เช่น:

- 🌐 เปิดเว็บ
- 📝 กรอกข้อมูล
- 🔍 ค้นหาข้อมูล
- 📸 ถ่าย screenshot

## การใช้งาน

### ตัวอย่างการใช้

```
@opencode ช่วยหาข้อมูลราคา iPhone 15 บนเว็บ Apple
```

```
@opencode กรอกฟอร์มลงทะเบียนนี้ให้หน่อย
```

## Use Cases

| Use Case | ตัวอย่าง |
|----------|----------|
| ค้นหาข้อมูล | หาราคาสินค้า |
| เปรียบเทียบ | เปรียบเทียบราคา |
| ลงทะเบียน | กรอกฟอร์มอัตโนมัติ |
| ติดตาม | ติดตามข่าวสาร |
